# Design Criteria — Detailed Scoring Rubric

Each criterion is scored on a 1-10 scale. Scores are absolute and calibrated against the anchors described in the main SKILL.md.

## Design Quality (Weight: 2x)

Evaluates whether all visual elements converge into a single cohesive experience.

| Score | Description |
| ----- | ----------- |
| 1-3 | A collection of parts. No visual identity. Colors clash or are arbitrary. Typography has no relationship to content. Images feel like stock filler. The page could belong to any product. |
| 4-5 | Some consistency attempts but the result is generic. A "seen it before" feeling. Colors follow a palette but the palette itself is uninspired. Layout works but has no personality. |
| 6-7 | A distinct mood is present. Most elements harmonize. The color palette, typography, and layout serve the content's purpose. A few elements break the harmony but the overall identity is clear. |
| 8-10 | "Museum quality." Every visual element converges into one unified experience. Color, type, imagery, spacing, and motion all reinforce a single identity. Removing any element would diminish the whole. |

### What to Look For

- Does the color palette evoke a specific mood?
- Do images and illustrations share a consistent style?
- Does the typography choice reinforce the brand personality?
- Is there a clear visual hierarchy guiding the eye?
- Do transitions and animations feel like part of the design or afterthoughts?

## Originality (Weight: 2x)

Evaluates whether a human designer would recognize intentional creative decisions.

| Score | Description |
| ----- | ----------- |
| 1-3 | Unmodified stock components. Obvious AI generation signs (purple gradients, generic hero sections, 3-column feature grids). Default library styling with content swapped in. |
| 4-5 | Some custom choices visible but the overall impression is template-based. Custom colors applied to a standard layout. One or two distinctive elements surrounded by defaults. |
| 6-7 | Many intentional creative choices. Layout breaks from templates in meaningful ways. Custom components or interactions. Some default remnants remain but do not dominate. |
| 8-10 | Distinctively creative approach that a designer would recognize as intentional. Unique layout strategies, unexpected color combinations that work, custom illustrations or typography. Cannot be mistaken for a template. |

### What to Look For

- Could this page be generated by prompting "make me a landing page for X"?
- Are there layout decisions that surprise you (in a good way)?
- Do interactive elements have custom behavior or are they library defaults?
- Is the content presentation unique to this specific product?
- Would a different product's content look wrong in this design?

## Craft (Weight: 1x)

Evaluates technical execution of design fundamentals.

| Score | Description |
| ----- | ----------- |
| 1-3 | Inconsistent spacing throughout. Typography hierarchy is broken or absent. Poor contrast makes text hard to read. Colors clash. No alignment grid is apparent. |
| 4-5 | Basic hierarchy exists but feels mechanical. Spacing is mostly consistent but lacks rhythm. Colors are safe but lack harmony. The design "works" but has no finesse. |
| 6-7 | Good hierarchy with clear heading levels. Consistent spacing system. Harmonious color palette with sufficient contrast. Minor details may lack polish but fundamentals are solid. |
| 8-10 | Polished details throughout. Micro-interactions enhance usability. Typography mastery with optical adjustments. Spacing has rhythm, not just consistency. Color usage is sophisticated with intentional accent patterns. |

### What to Look For

- Is there a consistent spacing scale (4px, 8px, 16px, 24px, etc.)?
- Do heading sizes follow a clear typographic scale?
- Do body text lines have appropriate measure (45-75 characters)?
- Are interactive elements clearly distinguished from static content?
- Do hover/focus/active states exist and feel intentional?
- Is there sufficient contrast for accessibility (WCAG AA minimum)?

## Visual Usability (Weight: 1x)

Evaluates whether visual hierarchy, affordances, responsive composition, and state presentation make the interface understandable. Functional acceptance and business behavior remain QA-owned.

| Score | Description |
| ----- | ----------- |
| 1-3 | Visual hierarchy obscures primary actions, affordances are misleading, or responsive composition makes content unreadable. |
| 4-5 | Primary actions are visually findable, but hierarchy, labels, state treatment, or small-screen composition is inconsistent. |
| 6-7 | Affordances, hierarchy, state presentation, and responsive layout are clear with minor visual ambiguity. |
| 8-10 | Visual cues make actions, state, priority, and navigation immediately legible across supported viewports and accessibility modes. |

### What to Look For

- Can you identify the primary action within 3 seconds of page load?
- Does the hierarchy make primary and secondary actions visually distinct?
- Do labels, focus treatment, validation, and states remain legible?
- Are loading, empty, success, and error states visually designed and distinguishable?
- Does responsive composition preserve reading order and action visibility?
- Do links and buttons look like their respective interaction roles? QA verifies their behavior.
