# 공통 AI 문체 패턴

한국어·영어 fast track이 공유하는 최소 패턴이다. 모든 처방보다 의미 불변이 우선한다. 원문에 없는 사실, 근거, 행위자, 의견, 감정, 1인칭, 비유, 시나리오를 추가하지 않는다.

### C1. 동의어 순환 (Elegant Variation) [P2]

**문제:** 같은 대상을 반복 회피 때문에 다른 단어로 계속 바꿔 부름.

**처방:** 원문의 지시 대상을 유지하면서 가장 명확한 기존 명칭 하나로 통일한다.

### C2. 지식 한계 면책 [P1]

**감지 표현:** “정확한 정보는 확인이 필요합니다”, “최신 정보와 다를 수 있습니다”, “Up to my last training update”, “based on available information”.

**처방:** 내용 없는 메타 면책만 삭제한다. 출처·확실성·모름에 관한 실제 주장은 보존하며 새 출처를 만들지 않는다.

### C3. 긍정적 결론 공식 [P1]

**감지 표현:** “밝은 미래가 기대됩니다”, “무한한 가능성이 열려 있습니다”, “The future looks bright”, “Exciting times lie ahead”.

**처방:** 원문의 전망·태도·확실성 수준을 유지해 공식적 포장만 줄인다. 구체적 다음 단계나 반대 의견을 새로 만들지 않는다.

### C4. 이모지 장식 [P1]

**문제:** 원문 장르와 무관하게 제목이나 목록에 이모지를 붙임.

**처방:** 이모지가 내용 토큰이나 사용자 지정 형식이 아닐 때만 제거한다.

### C5. 균일한 문단 길이 [P2]

**문제:** 모든 문단을 비슷한 길이로 맞춤.

**처방:** 기존 문장만 합치거나 나눠 리듬을 조정한다. 시제·순서·강조는 유지한다.

### C6. 강제 3단 구조 [P2]

**문제:** 짧은 글에도 도입·본론·결론 라벨을 기계적으로 붙임.

**처방:** 내용 없는 구조 라벨만 줄인다. 도입·결론에 포함된 주장이나 정보는 삭제하지 않는다.
